# Mission 2050

Interface PWA offline pour accompagner le jeu de cartes Mission 2050.

## Utilisation sur iPad

1. Ouvrir l'adresse GitHub Pages dans Safari.
2. Toucher le bouton Partager.
3. Choisir Ajouter a l'ecran d'accueil.
4. Lancer Mission 2050 depuis l'icone creee.

Apres une premiere ouverture en ligne, les fichiers sont gardes en cache pour un usage offline.
